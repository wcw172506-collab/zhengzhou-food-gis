# 郑州美食GIS系统

## 快速启动

### Windows用户
双击运行 `启动系统.bat` 文件即可自动启动前后端服务器。

### 手动启动

#### 1. 启动后端（端口 5000）
```bash
cd backend
npm install
node server.js
```

#### 2. 启动前端（端口 3000）
打开新的终端窗口：
```bash
cd frontend
npm install
npm run dev
```

## 访问系统

启动成功后，在浏览器中打开：
**http://127.0.0.1:3000**

## 重要：配置百度地图密钥

系统使用百度地图显示餐厅点位，必须配置API密钥才能正常显示地图。

### 获取密钥步骤：
1. 访问：https://lbsyun.baidu.com/
2. 注册/登录账号
3. 进入"控制台" → "应用管理" → "我的应用"
4. 点击"创建应用"
5. 填写信息：
   - 应用名称：郑州美食GIS系统
   - 应用类型：浏览器端
   - Referer白名单：`*`（允许所有域名）
6. 提交后复制获取的 **AK（密钥）**

### 配置密钥：
编辑文件：`frontend\src\pages\MapView.tsx`

找到第62行，将 `您的百度地图密钥` 替换为实际的AK：

```typescript
script.src = 'https://api.map.baidu.com/api?v=3.0&ak=您的百度地图密钥'
```

替换为：
```typescript
script.src = 'https://api.map.baidu.com/api?v=3.0&ak=这里填入您的AK'
```

保存文件后，刷新浏览器页面即可看到地图。
